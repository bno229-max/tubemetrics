1. Quem somos

O TubeMetrics (Fabiano Ferreira de Souza) é uma plataforma de análise de métricas de canais do YouTube. Este documento explica quais dados coletamos, por que coletamos, como usamos e quais direitos você tem sobre eles.

Ao usar o TubeMetrics, você concorda com as práticas descritas aqui. Se você não concorda, pedimos que não utilize a plataforma.

2. Dados que você nos fornece

Para liberar as análises gratuitas, pedimos um cadastro simples com:

  • Nome — para identificar sua conta;
  • Telefone — para contato sobre o produto;
  • E-mail — para identificação e comunicação.

Esses dados ficam armazenados no seu navegador (armazenamento local) e, quando a etapa de contas de usuário estiver disponível no servidor, passarão a ficar também em banco de dados próprio, sob as mesmas proteções descritas na seção Segurança.

3. Dados do YouTube que acessamos

O TubeMetrics funciona em dois modos, com níveis de acesso bem diferentes:

3.1 Análise pública (sem login)

Ao pesquisar qualquer canal, consultamos apenas dados públicos da YouTube Data API v3 — inscritos, views, vídeos, títulos e estatísticas que qualquer pessoa já vê no próprio YouTube. Nenhum login é necessário e nenhum dado privado de terceiros é acessado.

3.2 Dashboard do Criador (com login do Google)

Se você optar por conectar o seu próprio canal via login do Google, solicitamos as seguintes permissões (escopos), sempre de somente leitura:

  • youtube.readonly — ler metadados do seu canal e da lista de vídeos publicados;
  • yt-analytics.readonly — ler views, tempo de exibição, retenção de audiência e inscritos ganhos/perdidos;
  • yt-analytics-monetary.readonly — ler receita estimada, RPM e CPM, quando aplicável.

O TubeMetrics nunca publica, edita, exclui ou altera nada no seu canal. Nenhum escopo de escrita é solicitado. O acesso é usado exclusivamente para exibir métricas a você mesmo, dentro do seu próprio painel.

4. Uso dos Serviços de API do YouTube

O TubeMetrics usa Serviços de API do YouTube (YouTube API Services). Ao conectar seu canal, você também está sujeito aos Termos de Serviço do YouTube.

Para entender como o Google trata os dados que compartilhamos com os Serviços de API do YouTube, consulte a Política de Privacidade do Google.

Você pode revogar o acesso do TubeMetrics à sua conta do Google a qualquer momento, na página myaccount.google.com/permissions. Ao revogar, encerramos a sessão correspondente e apagamos o token de acesso associado do nosso banco de dados.

Como protegemos o token de acesso

  • O refresh token (a chave de acesso permanente que o Google emite) nunca chega ao seu navegador — fica somente no servidor;
  • É armazenado cifrado (AES-256-GCM) no banco de dados, não em texto simples;
  • Seu navegador recebe apenas um identificador de sessão aleatório, num cookie que o JavaScript da página não consegue ler;
  • Se o acesso for revogado (por você ou pelo Google), detectamos isso automaticamente e apagamos a sessão morta.

5. Como usamos os dados

Usamos os dados coletados para:

  • Exibir o relatório de análise do canal pesquisado ou conectado;
  • Calcular os cruzamentos estatísticos (melhor horário, tema que mais converte, nota do canal, etc.) — sempre por fórmula matemática, nunca por inteligência artificial;
  • Aplicar os limites do seu plano de assinatura;
  • Entrar em contato sobre o produto, quando necessário;
  • Melhorar a plataforma com base em uso agregado e anônimo.

Não vendemos seus dados pessoais a terceiros.

6. Com quem compartilhamos dados

Usamos os seguintes prestadores de serviço (subprocessadores) para operar a plataforma:

  • Google / YouTube API Services — fonte dos dados de canal e Analytics;
  • Vercel — hospedagem do site e das funções de servidor;
  • Google Firebase (Cloud Firestore) — banco de dados para sessões e histórico de crescimento de canais.

Cada um desses provedores tem sua própria política de privacidade e mantém suas próprias certificações de segurança.

7. Retenção e exclusão de dados

  • Sessões de conexão de canal ficam ativas enquanto você não desconectar ou revogar o acesso;
  • O histórico diário de inscritos/views (usado nos rankings de crescimento) é mantido por até 400 dias e depois descartado automaticamente;
  • Você pode pedir a exclusão dos seus dados de cadastro a qualquer momento pelo contato abaixo.

8. Segurança

Adotamos medidas técnicas para proteger os dados, incluindo cifragem de tokens sensíveis, cookies protegidos contra leitura por JavaScript (httpOnly) e comunicação sempre por HTTPS. Nenhum sistema é infalível, e nos comprometemos a agir rapidamente caso qualquer incidente seja identificado.

9. Cookies

Usamos dois tipos de armazenamento local:

  • Cookie de sessão (tm_session) — necessário para manter você conectado ao seu canal entre uma página e outra. Não é usado para rastreamento publicitário;
  • Armazenamento local do navegador — guarda preferências (tema claro/escuro, plano selecionado, histórico de pesquisas) diretamente no seu dispositivo.

10. Seus direitos, sob a LGPD

Conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento dos seus dados;
  • Acessar, corrigir ou solicitar a exclusão dos seus dados;
  • Solicitar a portabilidade dos seus dados a outro fornecedor;
  • Revogar o consentimento dado, a qualquer momento;
  • Ser informado sobre com quem compartilhamos seus dados.

Para exercer qualquer um desses direitos, use o contato na seção final desta página.

11. Uso por menores de idade

O TubeMetrics não é direcionado a menores de 18 anos e não coletamos intencionalmente dados de crianças ou adolescentes. Se você acredita que um menor nos forneceu dados, entre em contato para que possamos removê-los.

12. Alterações nesta política

Podemos atualizar esta política periodicamente. Mudanças relevantes serão comunicadas nesta mesma página, com a data de atualização revisada no topo.
